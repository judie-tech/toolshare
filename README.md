# ToolShare Backend

A peer-to-peer lending platform for tools, enabling users to list, search, and borrow tools via **USSD/SMS**, with airtime deposits as security. Built with Node.js/Express, MongoDB, and Africa’s Talking APIs.

---

## Key Features

- **USSD Integration**: List/search tools via USSD menus.
- **SMS Notifications**: Real-time alerts for loan requests and confirmations.
- **Airtime Deposits**: Micro-payments via Africa’s Talking Airtime API.
- **MongoDB Database**: Stores tools, loans, and user data.

---

## Technologies Used

- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **APIs**: Africa’s Talking (USSD, SMS, Airtime)
- **Tools**: Postman (testing), Ngrok (local tunneling)
